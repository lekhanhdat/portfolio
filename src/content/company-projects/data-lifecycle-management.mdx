## Overview

A large-scale enterprise platform for data governance and records management. I worked on the React and TypeScript frontend alongside product, QA and backend engineers.

## My contributions

- Built and extended reusable Fluent UI components: data tables, filters, pagination, dialogs, loading states and form validation.
- Implemented permissions, data classification, approval workflows, rule enforcement and job execution status.
- Integrated REST APIs with async requests, validation and error handling.
- Fixed UI state, pagination, date/time and i18n issues; refactored for reuse; took part in code reviews and cross-environment testing.

## Product scope

Permissions, data classification, approval workflows, rule enforcement and scheduled jobs for enterprise customers.

## Engineering highlights

- Reusable components shared across features, not one-off screens.
- Consistent async and error states across tables, dialogs and forms.
- Internationalized UI with locale-aware dates and times.
