## Overview

A large-scale enterprise platform for data governance and records management. I worked on its frontend with React and TypeScript, in a team of product managers, QA engineers, and frontend and backend developers.

## My contributions

- Built and extended reusable Fluent UI components: data tables, filters, pagination, dialogs, tooltips, loading states and form validation.
- Implemented business logic for permissions, data classification, records management, approval workflows, rule enforcement and job execution status.
- Integrated features with REST APIs: asynchronous requests, JSON processing, validation and error handling.
- Investigated and fixed issues in UI state, inconsistent API data, pagination, date/time handling and internationalization.
- Refactored existing code to improve component reuse while keeping existing behavior compatible.
- Tested and debugged features across development and testing environments, and took part in code reviews.

## Product scope

The platform supports data governance and records management for enterprise customers, including permissions, data classification, approval workflows, rule enforcement and scheduled jobs.

## Engineering highlights

- Reusable components shared across features rather than one-off screens.
- Consistent handling of asynchronous states and API errors across tables, dialogs and forms.
- Internationalized UI, including locale-aware date and time handling.
