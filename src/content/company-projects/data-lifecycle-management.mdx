## Overview

A large-scale enterprise platform for data governance and records management. I worked on its frontend with React and TypeScript, in a team of product managers, QA engineers, and frontend and backend engineers.

## My contributions

- Built and extended reusable Fluent UI components: data tables, filters, pagination, dialogs, loading states and form validation.
- Implemented business logic for permissions, data classification, approval workflows, rule enforcement and job execution status.
- Integrated features with REST APIs, including asynchronous requests, validation and error handling.
- Fixed issues in UI state, API data, pagination, date/time handling and internationalization.
- Refactored components for reuse, and took part in code reviews and testing across environments.

## Product scope

The platform supports data governance and records management for enterprise customers, including permissions, data classification, approval workflows, rule enforcement and scheduled jobs.

## Engineering highlights

- Reusable components shared across features rather than one-off screens.
- Consistent handling of asynchronous states and API errors across tables, dialogs and forms.
- Internationalized UI, including locale-aware date and time handling.
