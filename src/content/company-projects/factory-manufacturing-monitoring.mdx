## Overview

An Industrial IoT / MES web platform for monitoring production in a factory: OEE, production output, cameras, equipment alarms and product data. I was the main frontend contributor.

## My contributions

- Built OEE and production monitoring views with charts, cards and real-time device timelines.
- Developed a camera live and playback module with HLS streaming, multi-camera layouts, a playback timeline and a recording calendar.
- Moved product data management to server-side search, sorting, filtering and pagination, with inline editing.
- Built equipment alarm management: severity levels, real-time notifications and alarm actions.
- Developed production-order and machine operation workflows.

## Product scope

The product covers production monitoring, OEE, cameras, equipment alarms, product data and reporting.

## Engineering highlights

- Server state with TanStack Query: caching, refetching, request cancellation and payload mapping.
- Product data searched, sorted, filtered and paginated on the server instead of in the client.
- Responsive layouts across desktop, tablet and mobile, with loading, error and disabled states.
