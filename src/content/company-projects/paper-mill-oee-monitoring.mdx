## Overview

A production and OEE monitoring web application for a paper mill. I was one of the main frontend contributors.

## My contributions

- Built dashboard, OEE and statistics views: time-range filters, historical and real-time charts, KPI cards and alarm history.
- Added app-wide loading feedback, request cancellation on navigation and real-time alarm notifications.
- Built a production orders page and an in-app user guide.
- Built an interactive digital factory with 2D/360° maps and 3D models (Three.js, React Three Fiber): object selection, highlighting and context-aware camera controls.

## Product scope

The product covers production and OEE monitoring, statistics, production orders, 2D/360° and 3D factory views, and user management.

## Engineering highlights

- Cancelling in-flight requests on navigation to avoid rendering stale data.
- Time-range controls shared across dashboard, OEE and statistics views.
- 3D and 360° scenes integrated into a monitoring dashboard.
