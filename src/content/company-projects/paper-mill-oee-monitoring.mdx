## Overview

A production and OEE monitoring web application for a paper mill. I was one of the main frontend contributors.

## My contributions

- Built dashboard, OEE and statistics views: time-range filters, historical and real-time charts, KPI cards and alarm history.
- Added app-wide loading feedback, request cancellation on navigation and real-time alarm notifications.
- Built a production orders page and an in-app user guide.
- Built an interactive digital factory with 2D/360° maps and 3D models (Three.js, React Three Fiber): selection, highlighting and context-aware camera controls.

## Product scope

Production and OEE monitoring, statistics, production orders, 2D/360°/3D factory views and user management.

## Engineering highlights

- Request cancellation on navigation, so stale data never renders.
- Shared time-range controls across dashboard, OEE and statistics.
- 3D and 360° scenes inside a monitoring dashboard.
