## Overview

An energy management system for a factory: consumption, electricity cost, telemetry, assets, alarms and reports. A web app and a mobile app share one backend. I was the main engineer on the mobile app.

## My contributions

- Built consumption and cost charts, factory monitoring views and telemetry charts with date selection.
- Built asset and device screens with server-side search, filtering and pagination.
- Built alarm and report screens with time and type filters.
- Implemented role-based user management and authentication with token refresh.

## Product scope

The system covers energy consumption and cost monitoring, assets, alarms and reports, on the web and on mobile.

## Engineering highlights

- Built on Expo and React Native with the New Architecture.
- Server state with TanStack Query and forms with React Hook Form.
- Server-side filtering and pagination for asset, device and alarm lists.
