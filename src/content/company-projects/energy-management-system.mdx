## Overview

An energy management system for a factory: consumption, electricity cost, telemetry, assets, alarms and reports. A web app and a mobile app share one backend. I was the main developer of the mobile app; my work on the web app was limited to small changes.

## My contributions

- Home screen with yearly consumption and cost charts.
- Factory views: monitoring parameters, chart modals, telemetry line charts with date selection, and time-range cards.
- Assets and devices with detail pages, server-side search, filtering and pagination, and device–asset relationships.
- Alarms with time and type filters (moved to server-side filtering) and reports by date range.
- User management with role-based permissions, including a guard against deleting your own account.
- Authentication: token refresh handling with a warning when refresh fails, and the migration from API v1 to v2.

## Product scope

The web app includes a dashboard, energy monitoring, an energy flow tree, alarms, reports and settings. The mobile app brings monitoring, assets, alarms and reports to phones.

## Engineering highlights

- Built on Expo SDK 54 and React Native 0.81 with the New Architecture and React Compiler.
- Server state with TanStack Query and forms with React Hook Form.
- Push notifications with expo-notifications.
