## Overview

An energy management system for a factory, with web and mobile apps on one backend. I was the main engineer on the mobile app.

## My contributions

- Built consumption and cost charts, factory monitoring views and telemetry charts with date selection.
- Built asset and device screens with server-side search, filtering and pagination.
- Built alarm and report screens with time and type filters.
- Implemented role-based user management and authentication with token refresh.

## Product scope

Energy consumption and cost monitoring, assets, alarms and reports, on web and mobile.

## Engineering highlights

- Expo and React Native with the New Architecture.
- TanStack Query for server state, React Hook Form for forms.
- Server-side filtering and pagination for assets, devices and alarms.
